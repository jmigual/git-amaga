# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub:
<https://github.com/jmigual/git-amaga/security/advisories/new>

Include the affected version, what an attacker can do and steps to reproduce.

## Supported versions

Only the [latest release](https://github.com/jmigual/git-amaga/releases/latest) receives
security fixes.

## Scope

git-amaga has not been independently audited. What it does and does not protect against is
described in the "Security model and limitations" section of the [README](README.md#security-model-and-limitations).
